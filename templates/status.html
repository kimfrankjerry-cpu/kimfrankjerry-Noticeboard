Sync Agent Configuration

The Raspberry Pi sync agent must send a bearer token with every request. Configure the Pi agent to use the following endpoint and token:

GET /api/manifest
GET /api/media/<filename>
Authorization: Bearer <API_TOKEN from config.py>
The sync agent writes to sync_log.txt in the application root after each successful sync. The "Last Pi Sync" metric above reads the last line of that file.
